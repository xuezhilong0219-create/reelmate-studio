# 剧作工坊 · Reelmate Studio

本地 AI 影视创作工作台，按 [reelmate.cn](https://www.reelmate.cn) 的功能面复刻（**全部去付费**），零第三方依赖：Node 原生 http + 无构建静态 SPA + 本地 ffmpeg / 像素引擎出图出片。

## 快速开始

```bash
# 需要 Node ≥ 20，以及 PATH 里的 ffmpeg
node server/index.mjs
# 打开 http://127.0.0.1:8848
```

首次启动会自己创建 `data/`（db.json 与 media 目录），不需要任何安装步骤。

## 能力一览

- **工具箱 17 项**：文生视频 / 图生视频 / 参考生视频 / 视频超清 / 续写 / 编辑 / 参考 / 对口型 / 文生图 / 参考生图 / 文生音乐 / 文生音效 / 文生语音 / 配乐 / 局部重绘 / AI 特效 / Agent 灵感成片
- **平台 32 个页面**：项目与剧集分镜、剧本/小说改编、素材库与素材表、自由画布（12 种节点）、3D 导演台、剪辑台、图片后期 15 项、视频后期 6 项、影视项目壳与任务审核流、创作者中心、团队与权限、任务表格视图
- **结果可导出**：成片 MP4、ZIP 素材包、CSV 任务表、合同文本都在 `data/` 下落盘

## 目录
